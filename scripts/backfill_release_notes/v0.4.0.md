## box-open-sdk 0.4.0

Minor release: real public API added to every hand-written runtime — HTTP
client injection, retry disable, a custom token source, and default request
headers — plus a fix for a cross-language 401-retry-budget bug, and a run of
naming-correctness fixes in the spec/synthesis layer (duplicate collisions,
verb-first request-body names, ancestor-fallback naming, and more).

Changes since v0.3.1:

- readme: consistent release-version + license badges across all five SDKs ([#105](https://github.com/unofficialbox/box-gantry/pull/105))
- spec: fix three latent naming bugs (statuses, whitelist→allowlist, folders/0) ([#106](https://github.com/unofficialbox/box-gantry/pull/106))
- spec: fix two structural naming bugs (#-variation collisions, doubled IdId) ([#107](https://github.com/unofficialbox/box-gantry/pull/107))
- spec: name request bodies verb-first (`CreateFileRequest`, not `FileCreateRequest`) ([#108](https://github.com/unofficialbox/box-gantry/pull/108))
- spec: reject bare `Request`/`Response` declaration names ([#109](https://github.com/unofficialbox/box-gantry/pull/109))
- spec: fall back to the real ancestor, not a numeral, on name collisions ([#110](https://github.com/unofficialbox/box-gantry/pull/110))
- spec: preserve the parameter's own seed in its ancestor fallback ([#111](https://github.com/unofficialbox/box-gantry/pull/111))
- spec: reserve paginated fetch names, dedupe `base_api_version()` ([#112](https://github.com/unofficialbox/box-gantry/pull/112))
- spec: curate group-membership method/body names, drop the `CreateGroupRequest2` collision ([#113](https://github.com/unofficialbox/box-gantry/pull/113))
- spec: recognize nullable-`$ref` and `additionalProperties` idioms; add Box Query / Query Insights ([#114](https://github.com/unofficialbox/box-gantry/pull/114))
- runtime: HTTP-client injection, retry disable, open token source for every SDK wrapper ([#116](https://github.com/unofficialbox/box-gantry/pull/116))
- runtime: default client headers; fix a cross-language 401-retry-budget bug ([#117](https://github.com/unofficialbox/box-gantry/pull/117))
