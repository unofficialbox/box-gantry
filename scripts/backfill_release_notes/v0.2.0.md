## box-open-sdk 0.2.0

The published 0.1.2 predates this cycle's surface changes — the `auth`
package split (was `runtime`), friendlier operation names, record builders,
and real Quickstart READMEs. Those rename public API, so under pre-1.0
semver they warrant a minor bump. Registries are immutable, so 0.1.2 can't
carry the new output regardless; 0.2.0 re-releases the fleet from a clean,
honest version.
