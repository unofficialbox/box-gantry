## box-open-sdk 0.3.1

Patch release, fixing a release-tooling bug uncovered while shipping 0.3.0:
npm trusted publishing signs a provenance statement for the repo that runs
the release workflow (box-gantry) and requires the generated package's
`repository.url` to match it, but it pointed at box-open-ts-sdk instead —
npm rejected the 0.3.0 publish with E422. The generated `package.json` now
points `repository.url` at box-gantry (the repo that builds and provably
publishes the package); `homepage` still points a TypeScript consumer at
box-open-ts-sdk. Also makes the Java compile gates skip cleanly on a
pre-JDK-26 toolchain instead of failing outright.
