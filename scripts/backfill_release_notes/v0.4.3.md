## box-open-sdk 0.4.3

Patch release with a real behavior fix: every backend's multipart request
body (file upload, avatar upload) was JSON-marshalling the *entire* request
struct into a wrongly-wrapped `attributes` part and never sending the file's
bytes at all — the upload silently never happened. Java additionally
base64-encoded the file bytes into that same wrong JSON blob. Apex had no
multipart support at all. Fixed across all five backends with a shared,
structural classifier (the binary-typed field is the file part, everything
else is the JSON part) instead of each backend guessing the same fixed
two-field shape.
