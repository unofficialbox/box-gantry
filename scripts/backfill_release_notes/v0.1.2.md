## box-open-sdk 0.1.2

First public release of the box-gantry fleet: the full pipeline (OpenAPI
ingestion → typed IR → semantic analysis → capability manifest → per-backend
lowering) and five generated SDKs, each with a hand-written runtime, the four
Box auth flows (dev token, OAuth 2.0, Client Credentials Grant, JWT),
generated reference docs, and round-trip tests. This release adds real
landing-page READMEs and registry keywords/metadata on top of that base —
supersedes the short-lived 0.1.0/0.1.1 cuts, which shipped with a bare
README.

Highlights, in build order:

- **Engine core** — OpenAPI ingestion, typed IR, semantic analysis, and the
  runtime contract (M0–M2)
- **Go SDK** — full backend, all four auth flows, pagination, a hand-written
  runtime, live-smoke verified against the real Box API (M3)
- **Apex SDK** — model/manager/runtime layers, all four auth flows, an
  unlocked-package (2GP) ship artifact, 75%+ generated test coverage (M4)
- **Rust SDK** — async reqwest/tokio runtime, typed discriminated unions,
  async paginators, a publishable crate (M5)
- **TypeScript SDK** — fetch-based runtime, dual ESM/CJS npm artifact, live
  smoke (M6)
- **Java SDK** — java.net.http runtime (HTTP/3), a structured-concurrency
  chunked-upload orchestrator, a Maven ship artifact (M7)
- **Release prep** — per-language repository layout, the vendored runtime
  baked into every generated SDK, a single `SDK_VERSION` source of truth, and
  (this release) real landing-page READMEs with registry keywords
