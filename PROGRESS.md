**~90% complete by effort** — **v1 (Go SDK) is shipped**; v2 (Apex) is
essentially complete (models, native-JSON, managers/client, serialization
remap, server auth, generated tests, **VR-1.3 green** on-platform, **VR-1.4**
live smoke, **VR-3 conformance parity** (D-141), and the **NF-8 ship artifact**
— an unlocked 2GP package, defined with its CI build job wired (D-142)); v3 (Rust) and v4
(TypeScript) are feature-complete, and v5 (Java 26) has just been added to the roadmap.
When TypeScript was added as a fourth target (D-143) its expanded scope stepped
the overall figure down from ~84% to ~78% by effort (no work was lost); it
climbed back to ~91% as v3 reached parity and v4's backend landed — and adding
**Java 26 as a fifth target (D-164)** stepped it down again from ~91% to ~83%
(again, no completed work lost). **v4 (TypeScript) is capability-complete
and has its NF-8 ship artifact**: model layer, managers/client, `fetch` runtime
(all four auth flows), pagination, reference docs, and generated behavioral
tests all landed, so **`conform --target typescript` reads 9/9 and gates CI**
alongside Go/Apex/Rust (D-166); the **NF-8 npm ship artifact** — a publishable
dual ESM/CJS package that `npm publish --dry-run`s clean with shipped `.d.ts`
and loads through both `import` and `require` — is built and gated (D-167); and the **VR-7 live smoke** harness (D-168) drives
the runtime against a real Box account (one call per auth flow + paginate +
upload/download/delete), type-checked by the gate and run on demand via
`livesmoke.yml`. **v4 is feature-complete** — every TR-TypeScript acceptance
criterion is implemented and gated; the remaining step is an actual credentialed
live-smoke run + the release tag (a pipeline action, as with Go's tag). **v3
(Rust) is now feature-complete too**: with the runtime, conformance (9/9),
docs, pagination, generated tests, and VR-7 smoke already in place, the **NF-8
ship artifact** (D-169) closes the last gap — the release pipeline vendors the
hand-written runtime into the generated crate (as Go/TS ship self-contained) and
`cargo publish --dry-run`s clean, gated in `cargo test --workspace`. The large shared cost — the whole
engine core (ingestion, typed IR, semantics, manifest, runtime contract) and
the verification harnesses — landed with v1 and is **reused unchanged** by
v2/v3/v4/v5, so the remainder is mostly target-specific backends + runtimes.
